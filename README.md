X（旧Twitter）の投稿をブラウザ上でローカル翻訳できる Google Chrome 向けの拡張機能です。  
Preferred Networks（PFN）が開発した翻訳特化モデル **PLaMo 3 Translate**（0.8B / 2B / 8B / 31B）を採用しており、外部サーバーにテキストを送信することなく、プライバシーを完全に守ったまま安全に翻訳できます。

---

## 主な特徴

- 🔒 **完全ローカル処理（プライバシー保護）**  
  翻訳処理はすべてお使いのPC上（ブラウザ内）で実行されます。投稿本文や訳文が外部サーバーへ送信されることはありません。
- ⚡ **WebGPU / CPU 両対応**  
  WebGPU対応環境では高速なGPU推論と自動翻訳が利用可能です。非対応環境でもCPU推論に自動で切り替わります。
- 📝 **自然なインライン表示＆ストリーミング生成**  
  投稿のすぐ下に生成されたテキストからリアルタイムに表示されます。原文と訳文のワンクリック切り替えも可能です。
- 📖 **用語集機能**  
  固有表現や専門用語の訳語を登録可能（最大20組）。双方向翻訳やJSON形式でのインポート／エクスポートに対応しています。
- 📌 **コミュニティノート対応**  
  通常の投稿だけでなく、コミュニティノートや出典リンクの翻訳にも対応しています。

## インストール方法

### 配布ZIPを使用する場合
1. 配布されているZIPファイルをダウンロードし、任意の場所に解凍します。
2. Chromeで `chrome://extensions/` を開きます。
3. 右上の**「デベロッパーモード」**をオンにします。
4. 左上の**「パッケージ化されていない拡張機能を読み込む」**をクリックし、解凍したフォルダ（`extension` フォルダ）を選択します。

### Gitリポジトリからビルド・読み込む場合
1. このリポジトリをクローンします。
2. [Hugging Face（PFN公式）](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF/resolve/main/plamo-3-translate-0.8b-Q4_K_M.gguf) から `plamo-3-translate-0.8b-Q4_K_M.gguf` をダウンロードします。
3. ダウンロードしたファイルを `extension/models/plamo-3-translate-0.8b-Q4_K_M.gguf` に配置します。
4. Chromeの `chrome://extensions/` でデベロッパーモードを有効にし、`extension` フォルダを読み込みます。

## 基本的な使い方

1. **翻訳の実行**  
   Xを開くと、各投稿の上部に**「PLaMoで翻訳」**ボタンが表示されます。クリックするとその場で翻訳が始まります（軽量な0.8Bモデルが組み込まれているため、初回から追加ダウンロードなしですぐに使えます）。
2. **原文の表示 / 再翻訳**  
   翻訳後は「原文を表示」ボタンで元の文章に切り替えることができます。翻訳の途中で「停止」を押すと原文表示に戻ります。
3. **一時的なモデル切り替え**  
   翻訳ボタン横の歯車アイコンから、その投稿にのみ使用するモデルを一時的に変更できます。
4. **機能のオン / オフ**  
   拡張機能のポップアップ右上にあるトグルスイッチで、全タブの翻訳機能を一括で無効化できます（無効時はアイコンがグレーになり、翻訳ボタンが非表示になります）。

## 設定とカスタマイズ

ツールバーの拡張機能アイコンをクリックするとクイック設定パネルが開き、より細かい設定は「詳細設定」から行えます。

### ポップアップ（簡易設定）
- **既定の翻訳モデルの選択**
- **使用プロセッサの切り替え（GPU / CPU）**
- **自動翻訳のオン / オフ**
- **適用する用語集の選択**

### 詳細設定
- **翻訳言語の設定**: 翻訳先・翻訳対象の言語を変更（デフォルトはブラウザの優先言語）。
- **モデル管理**: より高精度なモデル（2B / 8B / 31B）のダウンロードや、手動で取得したGGUFファイル（Q4_K_M形式）のインポート・削除。
- **用語集管理**: 原語と訳語のペアを登録・編集。「双方向」を有効にすると逆方向の翻訳時にも適用されます。[ローカルAI翻訳UI](https://midorisawa.com/translate/) と互換性のあるJSON形式での入出力が可能です。

## 対応モデル一覧

| モデル | ファイルサイズ | 推奨環境・備考 |
| :--- | :--- | :--- |
| **0.8B** | 約 500 MB | 標準同梱。軽量で高速に動作します。 |
| **2B** | 約 1.81 GB | バランス型。詳細設定からダウンロード可能。 |
| **8B** | 約 5.28 GB | 高精度。64-bit WebAssemblyと十分な空きメモリが必要です。 |
| **31B** | 約 19.53 GB | 最高精度。64-bit WebAssembly、大容量メモリ、および**GPU環境が必須**です。 |
